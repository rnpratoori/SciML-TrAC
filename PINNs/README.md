# ⚛️ Physics-Informed Neural Networks (PINNs)

This module contains a tutorial and presentation on Physics-Informed Neural Networks (PINNs).

## 📚 Contents

-   `PINN_full.ipynb`: A Jupyter notebook with a full tutorial on PINNs.
-   `M1.pdf`: A presentation on PINNs.

## 🚀 Getting Started

To get started with PINNs, you can open the `PINN_full.ipynb` notebook in Jupyter Lab or Google Colab.

```bash
# Example of running Jupyter Lab
jupyter lab
```

## 🎯 Learning Objectives

After completing this tutorial, you will understand:

-   **PINN Architecture**: The components of a PINN and how to construct one.
-   **Physics-Informed Loss**: How to incorporate physical laws into the loss function.
-   **Applications**: How to apply PINNs to solve forward and inverse problems.
