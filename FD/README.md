# 🔢 Finite Differences (FD)

This module contains a tutorial on solving the implicit heat equation using Finite Differences.

## 📚 Contents

-   `implicit_HE_full.ipynb`: A Jupyter notebook demonstrating the full implementation of an implicit solver for the heat equation.

## 🚀 Getting Started

To run the tutorial, you can open the `implicit_HE_full.ipynb` notebook in Jupyter Lab or Google Colab.

```bash
# Example of running Jupyter Lab
jupyter lab
```

## 🎯 Learning Objectives

After completing this tutorial, you will understand:

-   **Finite Difference Method**: The basics of the finite difference method for solving PDEs.
-   **Implicit Schemes**: The advantages of implicit schemes for solving parabolic PDEs like the heat equation.
-   **Implementation**: How to implement an implicit solver in Python.
