# 🧪 SciML Examples

This directory contains various examples of Scientific Machine Learning applications.

## 📚 Contents

-   `cno_1d.ipynb`: 1D Convolutional Neural Operator example.
-   `ExampleApplications.pdf`: A document with example applications.
-   `hPINN.ipynb`: Example of a Hamiltonian PINN.
-   `PINN_discovery.ipynb`: PINN for discovering governing equations.
-   `PINN_fwd_data.ipynb`: PINN with forward data.
-   `PINN_inverse.ipynb`: PINN for inverse problems.
-   `wno_1d.ipynb`: 1D Wavelet Neural Operator example.

## 🚀 Getting Started

To run the examples, you can open the Jupyter notebooks in Jupyter Lab or Google Colab.

```bash
# Example of running Jupyter Lab
jupyter lab
```

## 🎯 Learning Objectives

By exploring these examples, you will learn about:

-   **Convolutional Neural Operators (CNOs)**: A variant of neural operators for learning mappings between function spaces.
-   **Hamiltonian PINNs (hPINNs)**: A type of PINN that conserves energy.
-   **PINN for Discovery**: How to use PINNs to discover the governing equations of a system.
-   **Inverse Problems**: How to use PINNs to solve inverse problems.
-   **Wavelet Neural Operators (WNOs)**: A type of neural operator that uses wavelets.
